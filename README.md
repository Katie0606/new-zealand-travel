# 南岛来信 · 新西兰旅行手册

中文、响应式的南岛五日自驾旅行网站。React 19 + TypeScript + Tailwind CSS 4 + Vite。

**2026 年 11 月 22–26 日 · 基督城 → Lake Tekapo → 皇后镇 · 2–3 人自驾**

## 预览

需要 Node.js 22.12+ 或 24 LTS。

```bash
npm ci
npm run dev
```

在自己电脑的浏览器访问终端显示的地址（默认 `http://localhost:5173`）。云端开发时运行相同命令，通过开发工具的端口面板转发 **5173** 后预览。应用绑定 `0.0.0.0`；不要把云机器的 localhost 当作公开网址。

```bash
npm run build       # TypeScript 检查 + 生产构建，输出 dist/
npm run preview     # 预览构建产物，默认 4173
```

`dist/` 可部署到任意静态网站托管服务；Vite 使用相对资源路径，也支持 GitHub Pages 仓库子目录。当前提交不代表已部署公开站点。

## 功能

- 五天行程切换，出发时间、驾驶时长、景点说明及拍照提醒。
- 南岛自驾路线示意图、各地点导航及 Google Maps 完整驾驶路线。
- 截图所提供的去回程航班和三处住宿记录。
- CNY / NZD 双币种支出，编辑参考汇率，2 或 3 人分摊，分类汇总、添加、删除和 CSV 导出。
- 分组行前准备清单、完成进度。
- 预算、人数、汇率、清单保存到当前浏览器 localStorage，无需账号；不跨设备同步。
- 本地打包图片，不依赖图库在线服务；导航及 NZTA 外链需网络。
- 适配手机、平板及桌面，键盘焦点和减少动态效果偏好。

## 数据说明

行程内容在 `src/data.ts`，页面在 `src/main.tsx`，样式在 `src/style.css`。

航班及住宿来自用户笔记；未写入乘客姓名或预订号码。The Quartermaster 的 ¥4,535 是用户截图记录，已作为可删除的初始预算项目，金额仍需核对订单。其余住宿、机票、租车等未提供金额，未虚构价格。汇率 4.3 为可编辑估算，并非实时数据。所有行程时刻为新西兰当地时间，航班抵达时间为对应机场当地时间。驾驶时间未含停车、休息或天气影响。

图片为景点或氛围参考，酒店图片不代表已预订房型。来源记录见 `public/images/CREDITS.md`。准确住宿地址、航班时刻、景点开放时间、预订及入境要求请在出发前核对。

## 浏览器测试

测试覆盖桌面和手机：每日行程、导航链接、无横向溢出、双币种计算、人数分摊、增删与导出、刷新持久化以及运行时错误。

云环境已自带 `/usr/bin/chromium`：

```bash
npm test
```

其他电脑可设置系统 Chromium 路径：

```bash
CHROMIUM_PATH=/path/to/chromium npm test
```

或安装 Playwright Chromium 后，使用其可执行文件路径作为 `CHROMIUM_PATH`。Playwright 配置会自动启动测试开发服务器。
